# מעצב חכם

אפליקציית סקיצות חכמה לעיצוב פנים והום סטיילינג — חי אפליקציות.

- פרויקטים ← חדרים עם מידות
- עיצוב על תמונה של החדר עם AI (Google Gemini) ומוצרים אמיתיים מהקטלוג
- לפני/אחרי, הערות לכל אלמנט, הכנה לדפוס (PDF)
- בדיקת מידות והתרעות לפי כללי המקצוע (`rules.js`)
- עובדת באנדרואיד ובאייפון (PWA), גיבוי ושחזור לקובץ
- מאגר משותף (Firebase) לקטלוג ולכללים
- תוכנית הבית: עורך קירות/דלתות/חלונות, סרטוט רקע (תמונה/PDF) עם כיול, מצב קיים מול תכנון, התרעות ממ"ד/קיר נושא
- תלת־ממד עם סיבוב והליכה, ייצוא DXF לאוטוקאד/סקצ'אפ/רביט

## קבצים
- `index.html` — מבנה ועיצוב
- `app.js` — הלוגיקה
- `rules.js` — כל הכללים והמידות (מוסיפים כללים רק כאן)
- `plan.js` — עורך התוכניות, תלת־ממד וייצוא DXF
- `vendor/` — Three.js ו-PDF.js (עותק מקומי, עובד גם בלי אינטרנט)
- `docs/course-rules.md` — סיכומי הקורס כפי שהועתקו מהמחברת
